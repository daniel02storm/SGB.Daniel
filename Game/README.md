###### 2D Platformer



Jump across fire, enemies and moving platforms to reach the treasure!

###### 

###### Controls



Keyboard support



A to go left

D to go right

Space to jump, time it again to Double Jump

R to start over after losing or winning



###### Winning and Losing



Reach the coin to win



if you are hit by an enemy or fall on fire you will die and lose, same happens if you fall off the map, you can use R to play again or just use the buttons on the screen.



###### How to run





Run .exe in Game folder
